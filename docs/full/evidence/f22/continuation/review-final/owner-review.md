# Наблюдения владельца по ревью F22

Владелец просмотрел пакет Excel и подтвердил запись трёх наблюдений
в результат этой части человеческого ревью.

| Что проверено | Наблюдение владельца |
| --- | --- |
| Ссылки на источники | Все ссылки фактов и гипотез разрешаются. |
| Статусы | В проверенных статусах расхождений не обнаружено. |
| Границы результата | Система явно разделяет создание тикета и восстановление доставки. |

Это оценка указанных аспектов пакета. Перечень проверенных по отдельности
строк и оценки каждого факта и каждой гипотезы пока не зафиксированы.
Поля оценок в [полном пакете](review.json) остаются открытыми.
